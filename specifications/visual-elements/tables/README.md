# Visual Elements - Tables Subdomain

5 specifications for table-related components.

## Files

1. `01-table-element.md` - Main Table element
2. `02-column-definition.md` - Column configuration
3. `03-filter-definition.md` - Filter system
4. `04-table-actions.md` - Table action buttons
5. `05-inline-editing.md` - Inline editing support

## Common Patterns

Table specs should include:
- Data binding
- Pagination
- Sorting
- Filtering
- Selection
- Row actions
