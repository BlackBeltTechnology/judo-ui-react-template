# Visual Elements - Containers Subdomain

5 specifications for container components.

## Files

1. `01-flex-container.md` - Flex container with layout properties
2. `02-tab-controller.md` - TabController and Tab elements
3. `03-button-group.md` - ButtonGroup container for actions
4. `04-card-layouts.md` - Card/Frame styling
5. `05-grid-sizing.md` - Grid column/row sizing system

## Common Patterns

Container specs should include:
- Layout algorithms
- Child element rendering
- Responsive behavior
- Styling/theming
