## Overview

Routing Integration defines how generated pages are registered in React Router using their generated route paths.

## Router Setup

```typescript
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import { UserListPageModel, UserViewPageModel, UserFormPageModel } from '~/models';
import * as Pages from '~/pages';

export function AppRouter() {
  return (
    <BrowserRouter>
      <Routes>
        {/* Generated routes */}
        <Route path={UserListPageModel.routePath} element={<Pages.UserList />} />
        <Route path={UserViewPageModel.routePath} element={<Pages.UserView />} />
        <Route path={UserFormPageModel.routePath} element={<Pages.UserForm />} />
        
        {/* Default route */}
        <Route path="/" element={<Navigate to="/pages/UserList" />} />
      </Routes>
    </BrowserRouter>
  );
}
```

## Auto-Generated Router

```typescript
// Generated by model file generator
import { allPageModels } from '~/models';

export function generateRoutes() {
  return allPageModels
    .filter(model => !model.openInDialog)
    .map(model => ({
      path: model.routePath,
      component: model.name
    }));
}
```
